Privacy Policy

Last updated: November 11, 2025

Introduction

Oddvision is a Chrome extension that helps you capture and analyze webpage content using AI. Your privacy is our top priority. This policy explains what data we handle and how.

Data We Access

Website Content

When you press Alt+1, Oddvision captures visible text from the current webpage. This text is sent to your chosen AI provider (Groq or OpenRouter) for analysis only when you press Alt+2.

  • Trigger: Manual only (keyboard shortcut)
  • Storage: Temporarily held in memory until AI responds
  • Sharing: Sent only to your selected AI provider using your API key

API Keys

You provide your own API keys for Groq and/or OpenRouter. These keys are:

  • Stored locally in your browser using Chrome's chrome.storage.local
  • Never transmitted to any server other than the AI provider you're authenticating with
  • Never shared with Oddvision developers or third parties
  • Fully under your control (you can delete them anytime in extension settings)

Data We Do NOT Collect

Oddvision does not collect, store, or transmit:

  • Personal identifiable information (name, email, address, etc.)
  • Browsing history or web activity tracking
  • Location data
  • Financial information
  • Health information
  • Analytics or usage statistics

Third-Party Services

Oddvision sends captured text to AI providers (Groq, OpenRouter) using your API keys. These services have their own privacy policies:

  • Groq Privacy Policy
  • OpenRouter Privacy Policy

We do not control these services. Review their policies to understand how they handle your data.

Data Retention

Captured text: Held in memory only while processing your request. Discarded immediately after AI responds.

API keys and settings: Stored locally in your browser until you remove them or uninstall the extension.

Permissions Explanation

Permission Why We Need It
activeTab Read visible page text when you press Alt+1
scripting Inject overlay UI to display AI responses
storage Save your API keys and preferences locally
api.groq.com Send requests to Groq AI (if you use Groq)
openrouter.ai Send requests to OpenRouter (if you use OpenRouter)

Your Rights

You have full control over your data:

  • Delete API keys: Go to extension settings and clear your keys
  • Stop using the extension: Disable or uninstall from chrome://extensions
  • Review stored data: Open Chrome DevTools → Application → Storage → Extensions

Children's Privacy

Oddvision is not directed at children under 13. We do not knowingly collect data from children.

Changes to This Policy

We may update this policy occasionally. Changes will be posted on this page with an updated "Last updated" date.
