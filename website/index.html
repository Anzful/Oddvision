Why Oddvision

Ultra‑stealth UI

Small, glassy corner widget. Subtle dots, minimal footprint. Looks like nothing. Does a lot.

Keyboard first

Capture, analyze, and flip styles with quick shortcuts. No clicks required.

Automatic failover

Groq first, then OpenRouter. If one hiccups, another answers seamlessly.

Built-in keys

Shared API keys are built into the extension. No separate server, no manual setup.

How it works

  1. 1

    Capture the page

    Press Alt+1. We extract visible text (ignoring scripts and styles) with a gentle touch.

  2. 2

    Analyze instantly

    Press Alt+2. Groq answers fast. If rate‑limited, we fail over to OpenRouter.

  3. 3

    View results overlay

    Press Alt+3 to show or hide the Oddvision overlay and read the answer.

Providers & limits

Free

Groq — Llama 3.3 70B

  • ~30 requests / minute
  • ~14,400 requests / day
  • Ultra‑low latency
Free

OpenRouter — MiniMax M2

  • ~20 requests / minute (free)
  • ~200 requests / day (free models)
  • Great backup capacity

Numbers may change over time. Oddvision automatically balances to stay responsive.

Use responsibly

Oddvision is for research, learning, and productivity. Don’t abuse rate limits, spam, or try to bypass site rules. Respect content owners and local law.

  • No automated scraping beyond what you actively view.
  • No harmful, illegal, or abusive usage.
  • API keys are built-in. No setup required.
